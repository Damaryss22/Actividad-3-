# Práctica 1 – Fundamentos de Desarrollo Web

## Descripción
Sirve como introducción al desarrollo web usando HTML5, CSS3 y JavaScript puro. El objetivo es construir una página web principal con un diseño personalizado y una funcionalidad básica.

## Tecnologías Utilizadas
-HTML5

-CSS3

-JavaScript (Vanilla)

## Estructura del Proyecto
practica1/
├── pagina principal.html   # Estructura del documento
├── pagina principal.css    # Hojas de estilo
└── pagina principal.js     # Código JavaScript

## Requisitos
Navegador web moderno

## Ejecución
Opción 1: Abrir de forma directa

Dirígete a la carpeta practica1/

Abre el archivo pagina principal.html haciendo doble clic o desde tu navegador preferido

Opción 2: Usando un servidor local (recomendado)

Si prefieres ejecutar el proyecto desde un servidor local, puedes hacerlo con Python:
-cd practica1-web/practica1
-python -m http.server 8000

## Scripts
Este proyecto no utiliza dependencias ni scripts de npm, ya que que solo esta desarrollado con HTML, CSS y JavaScript puro.

## Notas
-No requiere instalación de dependencias externas
-No necesita proceso de compilación
-Funciona directamente en cualquier navegador moderno
